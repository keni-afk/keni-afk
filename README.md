# Hola, soy Kenia Ventura 👋

**Desarrolladora de software** en Lima, Perú. Me especializo en integraciones y automatización de procesos para ERP y logística: addons para **SAP Business One**, servicios y APIs en **C# / .NET**, apps móviles en **Kotlin** y herramientas en **Python**.

## 🛠️ Lo que hago

- **SAP Business One**: addons (UI API, VB.NET), Service Layer / DI API e integración con servicios externos como la API de SUNAT.
- **Backend**: APIs y servicios web con C# / .NET Core y SQL Server.
- **Móvil**: apps Android con Kotlin (MVVM, Retrofit, coroutines) para almacén y picking con lectores de códigos.
- **Web**: React, TypeScript, HTML, CSS y JavaScript.
- **Soporte técnico**: sistemas de laboratorio clínico (LIS), interfaces con analizadores, impresoras de etiquetas y lectores de códigos de barras.
